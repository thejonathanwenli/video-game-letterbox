# Video Game Letterbox User Stories

## MVP

### While logged out

- Users can sign up for an account and log in.
- Users can view a list of games, including each game's cover, title, genres, release date, and community rating.
- Users can search the game catalog by title.
- Users can click a game to view its details, community rating, recommendations, and reviews, along with each review author's username.
- Users can click a review author's username to view that user's public profile, library, statistics, and reviews.

### While logged in

- Users can search the game catalog and add a game to their personal library.
- Users can view their personal library and filter it by status or genre.
- Users can set or change a game's status to Want to Play, Playing, Completed, or Dropped.
- Users can add or update an optional personal rating from 1 through 10.
- Users can change whether they recommend a game.
- Users can remove a game from their personal library.
- Users can write a review for a game in their library.
- Users can edit or delete a review that they created.
- Users can follow another user from that user's profile.
- Users can unfollow a user they currently follow.
- Users can navigate to a Following page that lists recommended games and recent reviews from the users they follow.
- Users can view statistics showing their library by status, games by genre, and personal-rating distribution.
- Users can log out.

## Post-MVP

- A review that has been edited shows an Edited label.
- Users can like or unlike reviews, with only one like per user per review.
- Users can comment on reviews and delete comments they created.
- Users can create named custom game lists and share them publicly.
- Users can mark a small number of games as favorites on their profile.
- Users can track the platform on which they played a game.
- Users can sort and filter game lists by title, date, genre, status, rating, and recommendation.
- Users can navigate through long game and review lists one page at a time.
- Users can view a chronological activity feed containing new reviews, ratings, recommendations, and completed games from users they follow.
- Users can compare their personal rating of a game with the community rating.
